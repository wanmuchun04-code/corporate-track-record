# Corporate Track Record — 企业行为档案

> 🇨🇳 **[中文版](README.zh-CN.md)**

**A source-backed, bilingual documentation repository of publicly
documented labor-conduct controversies and how downstream customers
responded — so job seekers and consumers can steer clear.**

Every entry is a *record*, not a verdict: it compiles what was publicly
reported, by whom, and when, with numbered links to the original sources.
Nothing here is legal advice. Inclusion ≠ finding of liability. If a fact
changes, the record is corrected — openly.

## Current scope

- **Blacklist only, for now** — companies with verified labor-practice
  controversies (mass "persuaded resignations", coercive job transfers,
  retaliation against workers, contract breaches toward new hires, etc.).
- A **red list** (exemplary employers) is planned. The folder schema
  (`cases/`) already supports it.
- See **[METHODOLOGY](METHODOLOGY.md)** for inclusion criteria, evidence
  levels ([OFFICIAL]/[MEDIA]/[PARTY]/[MARKET]) and anti-misidentification
  rules. **Read it before relying on any entry.**

## How to use this repository

1. **Job seekers** — before accepting an offer, check whether the employer
   (or its parent) has an entry; read the *Implications for workers* section.
2. **Consumers & supply-chain watchers** — the *Downstream customer
   responses* section shows which brands take labor compliance seriously
   and how (audit, statement, order pause, etc.).
3. **Researchers / journalists** — every claim carries its source; reuse
   with attribution (CC BY 4.0).

## Contributing & corrections

- New case → follow the template in **[CONTRIBUTING](CONTRIBUTING.md)**.
  Unsourced entries are rejected.
- Spot an error? Open an issue or PR; corrections are logged in the case
  file's *Corrections* section.
- Companies named here are welcome to respond — your reply, with a source,
  becomes part of the record.
