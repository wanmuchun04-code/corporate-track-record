# 企业行为档案 — Corporate Track Record

> 🇬🇧 **[English](README.md)**

**有信源背书的双语文档仓库:记录已被公开报道的用工争议,以及下游客户如何
应对——让求职者与消费者避坑有据可依。**

每条档案都是"记录"而非"判决":它汇总什么被公开报道、谁报道的、何时报道,
并给出来源原文的可点击编号链接。本仓库内容不构成法律意见。收录 ≠ 认定
有法律责任。事实如有变化,档案会公开更正。

## 当前范围

- **目前只做黑榜**——用工行为存在已核实争议的企业
  (批量"劝退"应届生、胁迫调岗、打击报复员工、对新人毁约等)。
- **红榜**(用工模范企业)已规划;目录结构(`cases/`)已为此预留,无需重构。
- 收录标准、证据等级([官方]/[媒体]/[当事方]/[市场])与防误伤规则见
  **[方法论](METHODOLOGY.zh-CN.md)**。**使用任何条目前请先读它。**

## 怎么用

1. **求职者** — 接 offer 前查一下雇主(及其母公司)是否有档案,读
   "对求职者的提示"一节。
2. **消费者 / 供应链观察者** — "下游客户应对"一节会写明哪些品牌重视
   劳工合规、以及如何行动(审计、声明、暂停订单等)。
3. **研究者 / 记者** — 每条事实都带信源,可按 CC BY 4.0 署名引用。

## 贡献与更正

- 新案件 → 按 **[CONTRIBUTING](CONTRIBUTING.md)** 模板提交,无信源不收录。
- 发现错误?提 Issue 或 PR;更正会记入档案的"更正记录"。
- 被记录的企业欢迎回应——附上信源的回应将成为档案的一部分。
